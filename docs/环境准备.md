# 环境准备与依赖说明

本项目使用**统一的 Python 虚拟环境**，同时支持翻译脚本（`python-docx`）和 AI 检测 skill（`spacy` 等）。

---

## 自动配置流程（推荐）

首次使用时，运行环境配置脚本：

```bash
# 交互式模式（手动运行）
python setup_env.py

# 非交互式模式（AI 助手自动化执行）
python setup_env.py --non-interactive --env-type conda --env-name doc_translation
python setup_env.py --non-interactive --env-type venv --env-name .venv_paper_detection
```

> **使用 AI 助手时的工作流程**：
>
> - AI 助手会先**向你询问环境配置选项**（使用 Conda 还是 venv、环境名称等）
> - 然后使用**非交互式模式**自动运行配置脚本，无需你手动打开终端
> - 脚本支持 `--non-interactive` 参数，允许通过命令行参数指定所有配置选项
> - 这样 AI 助手可以在获取你的配置意图后，直接执行完整的环境配置流程

脚本会自动检测你的环境并引导配置：

1. **有 Conda**

   - 询问虚拟环境名称（默认 `doc_translation`）
   - 自动创建环境：`conda create -n <环境名> python=3.11 -y`
   - 自动安装当前依赖：`pip install -r requirements.txt`
   - 生成配置文件 `.project_env.json` 记录环境信息
2. **无 Conda 但有 Python 3.11+**

   - 询问是否创建 venv（推荐使用 `.venv_paper_detection/`）
   - 自动创建环境：`python -m venv .venv_paper_detection`
   - 自动安装当前依赖
   - 生成配置文件
3. **Python < 3.11**

   - 询问是否升级 Python
   - 提供升级指南（不会擅自操作）
   - 升级后重新运行脚本
4. **无 Python**

   - 提供 Python 安装指南
   - 退出配置流程

> **重要提示**：
>
> - 配置完成后，`.project_env.json` 会记录环境信息，后续无需重复配置
> - 首次运行 `/paper-detection` skill 时，选择已创建的虚拟环境，skill 会自动安装其所需的额外依赖（spacy, numpy, pandas 等）
> - skill 会生成自己的 `.env_status.json` 记录环境，后续运行直接使用

## 手动配置流程（可选）

如果不想使用自动脚本，可以手动配置：

```bash
# === 方式 A：使用 Conda（推荐） ===
# 1. 创建虚拟环境
conda create -n doc_translation python=3.11 -y
conda activate doc_translation

# 2. 安装当前依赖
pip install -r requirements.txt

# 3. 手动创建配置文件（可选）
# 创建 .project_env.json 记录环境信息


# === 方式 B：使用 venv ===
# 1. 创建虚拟环境
python -m venv .venv_paper_detection

# 2. 激活环境
# Windows PowerShell:
.\.venv_paper_detection\Scripts\Activate.ps1
# Linux/Mac:
source .venv_paper_detection/bin/activate

# 3. 安装当前依赖
pip install -r requirements.txt
```

## 分享给他人使用

本项目设计为**分享友好**：

- `.project_env.json` 和 `.env_status.json` 已加入 `.gitignore`（本地配置文件）
- 其他用户克隆项目后，首次运行 `python setup_env.py` 会自动触发环境配置
- 每个用户可以根据自己的环境（Conda/venv）独立配置，互不干扰

## 虚拟环境与依赖详解

### 环境配置流程

1. **项目初始化**（首次使用）

   - 运行 `python setup_env.py` 自动配置环境
   - 脚本会询问环境类型（Conda/venv）和环境名称
   - 自动安装当前依赖（仅 `python-docx`）
   - 生成 `.project_env.json` 记录环境信息
2. **skill 依赖安装**（首次使用 `/paper-detection` 时）

   - skill 会检测并询问是否使用已创建的虚拟环境
   - 选择项目环境后，skill 自动安装其所需依赖（`spacy`, `textstat`, `numpy`, `pandas`, `tqdm`）
   - skill 生成 `.env_status.json` 记录环境配置
   - 后续运行 skill 直接使用记录的环境

### 依赖分层

| 阶段           | 依赖                                                                               | 安装时机                            |
| -------------- | ---------------------------------------------------------------------------------- | ----------------------------------- |
| 项目初始化     | `python-docx`                                                                    | `setup_env.py` 自动安装           |
| skill 首次使用 | `spacy`, `textstat`, `numpy`, `pandas`, `tqdm` + `en_core_web_sm` 模型 | `/paper-detection` skill 自动安装 |

### 环境验证

激活虚拟环境后，可以验证依赖是否正确安装：

```bash
# 激活环境
conda activate doc_translation  # 或 source .venv_paper_detection/bin/activate

# 验证翻译依赖
python -c "import docx; print(f'python-docx {docx.__version__}')"

# 验证检测依赖（首次使用 skill 后）
python -c "import spacy; nlp = spacy.load('en_core_web_sm'); print(f'spacy {spacy.__version__}, model loaded')"
```
