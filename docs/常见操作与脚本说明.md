# 常见操作与脚本说明

## 常见操作

| 需求          | 操作                                                                                                                                                                                         |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 翻译新论文    | 在 `input/` 中放入 docx，运行 `extract_text.py`，在 `output/<文件名>/` 创建 `<文件名>_translation.md`，依次走步骤 2–6                                                               |
| 修改某一章节  | 编辑 `output/<文件名>/<文件名>_translation.md` 对应段落，对该段重跑 humanizer，并同步更新对照表与检测报告                                                                                  |
| 只重新润色    | 对 `output/<文件名>/<文件名>_translation.md` 重跑 `/humanizer`（**按步骤 4 的批次分章节调用，勿整篇一次性跑**），覆盖 `_translation_humanized.md` 与 `_humanize_comparison.md` |
| 只重新检测    | 对 `output/<文件名>/<文件名>_translation_humanized.md` 重跑 `/paper-detection`，覆盖 `_ai_detection_report.md`                                                                         |
| 生成最终 docx | `python build_docx.py output/<文件名>/<文件名>_translation_humanized.md`                                                                                                                   |
| 调整字体/字号 | 编辑 `build_docx.py` 顶部的 `DEFAULT_FONT` / `BODY_SIZE` / `REF_SIZE`                                                                                                                     |
| 清理临时文件  | 删除 `output/<文件名>/` 目录中的中间产物                                                                                                                                                   |

---

## 脚本与 Skill 说明

| 组件                              | 作用                                                                                                                                                                                                                    | 是否需要修改           |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `setup_env.py`       | 自动检测并配置 Python 虚拟环境，生成 `.project_env.json` 记录环境信息                                                                                                                                                 | 否                     |
| `extract_text.py` | 解压 docx 并解析其中的 `word/document.xml`，按段落和表格顺序输出；自动将 Word 中的上下标 run 转为 Unicode 上下标字符，表格转为 Markdown 表格格式，确保后续流程的上下标和表格信息不丢失                                | 否                     |
| `build_docx.py`     | 解析 markdown，按 Heading / 段落 / 表格构建 Word 文档；自动将 Unicode 上下标字符（`⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻` / `₀₁₂₃₄₅₆₇₈₉`）转为 Word 原生 superscript / subscript 格式，Markdown 表格转为 Word 原生表格 | 仅在需要调整全局样式时 |
| `/humanizer` skill              | 识别并去除英文文本的 AI 写作痕迹，使其更像人类手笔                                                                                                                                                                      | 否（外部 skill）       |
| `/paper-detection` skill        | 对英文学术文本逐句评估 AI 生成可能性，出具综合概率与逐句理由                                                                                                                                                            | 否（外部 skill）       |

两个 Python 脚本均为模板的固定组成部分，对任何论文都通用。**每篇新论文唯一需要手工产出的内容是在 `output/<输入文件名>/` 目录下创建 `<输入文件名>_translation.md` 的英文译文**，其余 `_translation_humanized.md`、`_humanize_comparison.md`、`_ai_detection_report.md` 均由对应 skill 生成。
